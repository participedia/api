## Translation API (Legacy Branch)

If you need to return to the Translation API that translates text, use the
`old-translations-api` branch.

To restore that logic in `master`, merge `old-translations-api` into `master`.

You also need to add `GOOGLE_TRANSLATE_CREDENTIALS` (with its value) to your
environment variables.
